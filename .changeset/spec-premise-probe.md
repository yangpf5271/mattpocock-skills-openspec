Treat current-state claims as facts to verify, across the flow: `grilling` verifies a decision's premises about what already exists before pinning them (a failed premise becomes a new frontier question, an unverifiable one is marked unverified); `implement` checks the spec's assumptions before coding and routes a false premise back to the spec instead of improvising; `implement-spec` verifies premises before launching parallel implementers and its implementers report back when code contradicts the ticket's assumptions; `grill-with-docs` reads the atlas's processes and symbols first when the region is mapped.
